Shell Stuff

Command Action
nhs deploy system config: nh os switch, auto-detects the active host
nht test a build without writing to the bootloader
nhc clean old generations, keep the last 7
jc "message" auto-commit handler that joins multi-word messages cleanly
nrs / nrt hard rebuild fallback: nixos-rebuild switch/test via sudo
hardto <host> (installer shell only) scaffold a fresh host profile from 0_TEMPLATE with the live hardware configs
jnconf jump to the config dir: cd ~/nix-config
jars pull the latest config: git pull --rebase origin main
ff fastfetch system info
nv / zd / code editor shortcuts nvim / zeditor / codium
chkhrd storage check: lsblk && fdisk -l
, quick nix-shell: , git curl for interactive, , git curl -- ls for one-shot
