# What is this Jar?

This Jar holds: `user packages[Apps, Tools]` `display prefrences [like WM settings]` `shell [like zsh settings]`.
All settings within this in some way affects the User experience in terms of user named `jar`.

**What lives Here:**
 - App specific settings/configs go within `app-bin[will be changed to app-jar soon]`.
 - WindowManager or other related things go within `ui-jar`.
 - Specific settings like `git` and `zsh` is placed here.
 - User Settings and Home stuff goes within `default.nix`.
